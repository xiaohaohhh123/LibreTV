# 私人TV 本机入口

Windows 双击源码根目录的 `启动私人TV.cmd`，浏览器会打开 <http://127.0.0.1:8080/>，无需输入密码。双击 `停止私人TV.cmd` 停止本项目服务。两者不删除历史、待看或浏览器设置。

首次运行需要 Node.js 22 或更新的长期支持版以及 npm；脚本会在缺少依赖时执行 `npm ci`，缺少或落后于源码的生产构建时执行 `npm run build`。安装依赖需要网络。错误会保留窗口，服务日志位于源码根的 `.local-preview/server.log`。

入口固定为 127.0.0.1:8080，不提供局域网访问。重复启动已有健康的当前版本时只打开浏览器；其他程序占用 8080 时明确拒绝，不结束不相关进程、不自动改端口。修改源码后再次双击会重建并替换本项目旧服务。

专用启动器创建真正只监听 127.0.0.1 的 HTTP Server。服务端鉴权检查显式本机模式及进程中该活动监听器的实际地址；仅设置环境变量、请求头、查询参数或前端开关均不能开启免密码。启动器还核对本机连接和精确 Host，拒绝浏览器跨站停止请求。

普通 `npm run dev`、`npm start`、Docker 和线上部署均默认保持原密码鉴权。本机入口未使用或写入任何固定绕过口令、会话令牌或线上秘密。`local-sources.json` 只缓存本项目原先公开配置的四个采集源，重新启动不读取线上状态，也不修改线上配置。用户浏览器原有配置仍按现有合并规则保留。

维护检查：`/api/status` 提供 `localPreview` 和 `previewBuildId`；专用本机 `/__private_tv_preview` 提供 PID、构建编号及本工作树摘要。`.local-preview/` 仅存启动锁与日志，不入源码包。关闭本机服务后，普通启动仍要求配置 PASSWORD；未配置返回 503。
